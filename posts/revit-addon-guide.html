Revit Add-in Guide for Beginner by using pyRevit

Nếu bạn muốn bắt đầu tạo tool cho Revit nhưng chưa sẵn sàng đi thẳng vào C# add-in, thì pyRevit là con đường rất dễ tiếp cận để prototype nhanh và học workflow.

1. pyRevit là gì?

pyRevit là một môi trường giúp bạn viết các tool chạy trong Revit bằng Python. Nó phù hợp cho automation, utility nhỏ, UI cơ bản, và thử nghiệm ý tưởng nhanh.

2. Khi nào nên dùng pyRevit?

  • Khi bạn muốn làm tool nội bộ nhanh.
  • Khi cần thử ý tưởng trước khi viết add-in chính thức.
  • Khi muốn học Revit API theo cách dễ tiếp cận hơn.

3. Cấu trúc extension cơ bản

Một extension pyRevit thường có dạng:

MyExtension.extension/
                                └── MyTools.tab/
                                    └── Demo.panel/
                                        └── Hello.pushbutton/
                                            ├── script.py
                                            └── icon.png

4. Script đầu tiên

Tạo file script.py:

from pyrevit import script

                    output = script.get_output()
                    output.print_md("# Hello from pyRevit")
                    output.print_md("Đây là tool đầu tiên của bạn trong Revit.")

5. Những thứ beginner nên học tiếp

  • Document, UIDocument, Selection
  • FilteredElementCollector
  • Transaction
  • Forms/UI cơ bản
  • Tổ chức tool theo tab/panel/button

6. Lộ trình đề xuất

  1. Làm tool chỉ đọc dữ liệu
  2. Làm tool chọn element
  3. Làm tool chỉnh sửa parameter với transaction
  4. Thêm UI chọn option
  5. Tách common functions để tái sử dụng

7. Kết luận

pyRevit rất phù hợp để bắt đầu. Khi bạn hiểu rõ workflow, API, và pattern tổ chức code, bạn có thể tiến lên những add-in lớn hơn với kiến trúc tốt hơn.
